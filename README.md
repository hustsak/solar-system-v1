# Cosmos Observatory
### 3D Solar System & Astronomical Museum  
**(ប្រព័ន្ធព្រះអាទិត្យ)**

An interactive, bilingual (English ↔ Khmer) 3D solar-system explorer and educational astronomical museum built for the web.

**Live Demo:** [https://solarsystem-chi-umber.vercel.app/](https://solarsystem-chi-umber.vercel.app/)

---

## Overview

**Cosmos Observatory** is a browser-based interactive experience that lets users explore the Solar System in real-time 3D. It combines:

- Accurate orbital motion of the planets
- Detailed scientific data for each world
- An educational “museum” mode with facts, missions, and taxonomy
- A dedicated **Solar & Lunar Eclipse 3D Laboratory**
- Full bilingual support (English + Khmer / ភាសាខ្មែរ)

The project is designed as both a visual spectacle and a learning tool — especially useful for Cambodian students and educators.

## Features

### 🌌 3D Solar System View
- Real-time orbital motion of the Sun and all 8 planets
- Click any planet to focus the camera and open its detail panel
- Toggle orbit lines, pause/play motion, reset camera
- Smooth zoom, rotate, and focus controls

### 🪐 Planetary Information
Each planet includes:
- Bilingual name (English + Khmer)
- Scientific type (Terrestrial, Gas Giant, Ice Giant…)
- Description, key facts, and past/present space missions
- Visual gradient / color representation

## How to Use

1. Open the live site in a modern browser (Chrome / Edge / Firefox recommended).
2. Wait a few seconds for the 3D scene to load.
3. Use mouse / trackpad to rotate and zoom.
4. Click any planet to focus and view details.
5. Use the top controls to:
   - Pause / resume orbital motion
   - Toggle orbit lines
   - Switch language
   - Enter Observatory / Museum mode
   - Open the Eclipse Laboratory
6. Use the search bar to quickly find planets or topics.
